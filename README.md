# 🐍 Python-тренажёр

Бесплатный тренажёр по Python для подростков: объяснения простыми словами, тесты и задачи с автоматической проверкой кода прямо в браузере. Регистрация не нужна, прогресс сохраняется в браузере.

**Открыть сайт:** https://smirsnow.github.io/python-trainer/

## Темы

1. Вывод на экран: `print()`
2. Переменные и типы данных
3. Арифметика и строки
4. Ввод данных: `input()`
5. Условия: `if`, `elif`, `else`
6. Цикл `for` и `range()`
7. Цикл `while`
8. Списки

В каждой теме есть объяснение и 20–25 задач трёх видов: тест, «что выведет программа?» и «напиши код». Код проверяет настоящий Python ([Pyodide](https://pyodide.org)), который работает прямо в браузере. Есть песочница для свободных экспериментов.

## Как устроен проект

| Файл | Что это |
|---|---|
| `index.html` | Готовый сайт: его и показывает GitHub Pages |
| `src/tasks.py` | Все темы, объяснения и задачи. **Чтобы что-то поменять в содержании — правьте здесь** |
| `src/template.html` | Внешний вид и логика страницы |
| `src/build.py` | Сборщик: проверяет все ответы и решения и собирает `index.html` |

### Как пересобрать сайт после правок

Нужен установленный Python 3. В папке проекта:

```
python src/build.py
```

Сборщик сам запустит каждое решение и каждый пример, вычислит правильные ответы и в конце напишет `ERRORS []`, если всё в порядке. Затем отправьте изменения на GitHub:

```
git add .
git commit -m "Что поменялось"
git push
```
